# Validador de Oferta X1

Skill para Claude que valida se uma ideia de produto serve para o X1 low ticket (venda por WhatsApp, entrega primeiro e paga depois). Feita pelo canal IgorComicsTV.

## O que ela faz

- Nota 7 critérios: tangibilidade, praticidade, velocidade do resultado, preço, público, entrega por WhatsApp e clareza da promessa.
- Aponta riscos de anúncio.
- Dá o veredicto (recomendo, recomendo com ajustes, não recomendo), alternativas e um próximo passo.
- Compara 2 ou 3 ideias lado a lado.

## O que ela não faz

Não escreve copy, não monta fluxo, não cria roteiro de anúncio e não mexe em campanha. É uma ferramenta de apoio para decidir o que testar, não garantia de resultado.

## Como instalar

Primeira vez com Claude Code? Siga o passo a passo para iniciantes: [INSTALAR.md](INSTALAR.md).

Resumo para quem já usa:

1. Baixe esta pasta.
2. Copie para `~/.claude/skills/validador-de-oferta-x1/` (o arquivo `SKILL.md` precisa ficar dentro dessa pasta).
3. Abra o Claude Code e escreva, por exemplo: `valida minha oferta: receitas de pão de queijo em PDF por R$ 12`.
